03 / Open Source · Python

Deine Daten.
Ein neuer Anfang.

SpasstoCSV hilft beim Wechsel von Samsung Pass zu einem anderen Passwortmanager. Die Konvertierung läuft lokal auf deinem Computer.

Projekt auf GitHub
Formatbeispiel mit erfundenen Daten

Erfundener, gekürzter Datensatz zur Illustration. Der Konverter läuft lokal, nicht auf dieser Website. Klartext-Exporte enthalten sensible Daten.

Was hinter dem Projekt steckt
01 / DAS PROBLEM

Ein Export ist noch kein Umzug.

Samsung-Pass-Exporte liegen im .spass-Format vor. Ein anderer Passwortmanager erwartet ein anderes Datenformat.

02 / DER ANSATZ

Die Daten bleiben lokal.

Das Python-Tool entschlüsselt den Export lokal. Zielformate: Raw-CSV, Chrome-CSV, Proton-CSV und Bitwarden JSON. Details und Grenzen stehen in der verlinkten Projekt-README.

03 / WICHTIG

Mit Klartext bewusst umgehen.

CSV- und JSON-Ausgaben enthalten sensible Daten im Klartext. Nach dem Import löschen und niemals öffentlich teilen.
