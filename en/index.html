What is behind the project
01 / THE PROBLEM

An export is not yet a move.

Samsung Pass exports come in the .spass format. Other password managers expect a different data format.

02 / THE APPROACH

The data stays local.

The Python tool decrypts the export locally. Target formats: raw CSV, Chrome CSV, Proton CSV and Bitwarden JSON. Details and limits are in the linked project README.

03 / IMPORTANT

Handle plain text with care.

CSV and JSON output contains sensitive data in plain text. Delete it after importing and never share it publicly.
